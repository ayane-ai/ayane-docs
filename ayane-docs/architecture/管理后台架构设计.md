# 管理后台架构设计

上位架构：[项目整体架构设计](项目整体架构设计.md)

产品目标：[产品愿景与总纲](../product/产品愿景与总纲.md)

## 1. 仓库定位

`ayane-admin-web` 是面向项目维护者和管理员的独立 Web 前端，不属于 `ayane-client`，不依赖 Unity。

## 2. 功能范围

- 用户和角色管理。
- AI Identity 管理。
- Memory 查看、修正和删除。
- Session 查看和调试。
- 模型供应商配置。
- Prompt 配置。
- 功能开关。
- Agent Runtime 状态。
- 日志、错误和审计查看。

## 3. API 边界

```text
Admin Web
    ↓ 管理员鉴权
Admin API
    ↓
ayane-agent-service
```

管理后台不能使用 Client API 绕过管理员权限，也不能直接访问数据库。

## 4. 权限分层

- 只读管理员：查看用户、Session、Memory 和日志。
- 内容管理员：管理 Identity、Memory 和 Prompt。
- 系统管理员：管理模型配置、功能开关、权限和基础设施状态。
- 所有高权限操作必须进入审计日志。

## 5. 与客户端的区别

| 维度 | 管理后台 | 普通客户端 |
| --- | --- | --- |
| 使用者 | 管理员 | 普通用户 |
| 接口 | Admin API | Client API |
| 权限 | 高权限、可审计 | 用户级权限 |
| Unity | 不依赖 | 通过客户端 Bridge 可选接入 |
| 发布 | 独立 Web 发布 | Android、Desktop、iOS 独立发布 |
